## Ключевые решения по позиционированию (зафиксированы)
- **Луми = центральный проводник-друг**, единая точка входа. Формула: «спроси Луми — отведёт куда нужно».
- **Тиндер-места — ядро местной петли, но ОДИН из флоу** (рядом: впечатления, карта, компания, афиша).
- **Два двигателя:** 💸 турист (впечатления крыши/кораблики/авторское → бронь = деньги-сейчас) +
  🔁 местный (настроение→свайп→маршрут→компания→память→возврат = удержание).
- **Старт = сапплай впечатлений** (ранний кэш), привычку местных валидируем параллельно (PoL «консьерж-Луми»).
- Бренд = **Луми (Lumi)**, персонаж — девушка-подруга. Категория — «AI-друг города».

## Текущий фокус / очередь
1. Дока-пакет экранов готов (карта, пайплайн, главный, впечатления, свайп) — **стоп-док**.
2. Старт-экзекьюшн: обзвон 5–8 операторов (PoL-1) + лендинг впечатлений (ручная бронь до кредов).
3. Параллельно: PoL «консьерж-Луми» (валидация привычки местных).
4. Поддержка dev: уточнять поля/флоу впечатлений и брони по мере сборки.
