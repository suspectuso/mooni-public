# Habits Tracker Frontend

Next.js Telegram Mini App

## Установка

```bash
npm install
```

## Настройка

Создайте `.env.local`:

```
NEXT_PUBLIC_API_URL=http://localhost:3001
```

## Запуск

```bash
npm run dev
```

Приложение будет доступно на http://localhost:3000

## Дизайн

- Фон: #262626
- Акценты: #fc2a0d (красный), #e6f43f (желтый)
- Минималистичный дизайн без градиентов
- 3 раздела: Лидерборд, Трекер, Профиль

## Функции

- Авторизация через Telegram
- Аватарка из Telegram
- Редактирование био
- Создание и трекинг привычек
- Система очков
- Лидерборд
