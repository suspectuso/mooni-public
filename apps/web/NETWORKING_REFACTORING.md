# Networking Page Refactoring

Полный рефакторинг страницы networking с разбиением на подкомпоненты и хуки.

## Структура проекта

```
front/
├── app/networking/
│   └── page.tsx                          # Главная страница (рефакторенная)
├── components/networking/
│   ├── ProfileCard/                      # Компоненты карточки профиля
│   │   ├── ProfileCard.tsx               # Главный компонент
│   │   ├── ProfileCardContainer.tsx      # Контейнер с анимациями
│   │   ├── ProfileCardPhoto.tsx          # Фотография
│   │   ├── ProfileCardAura.tsx           # Аура
│   │   ├── ProfileCardCases.tsx          # Кейсы
│   │   ├── ProfileCardButtons.tsx        # Кнопки
│   │   ├── ProfileCardInfo.tsx           # Информация
│   │   ├── ProfileCardTags.tsx           # Теги
│   │   └── index.ts                      # Экспорты
│   ├── AdCardWrapper.tsx                 # Обертка для рекламы с тряской
│   ├── CardHeader.tsx                    # Заголовок (город + looking for)
│   ├── SwipeIndicators.tsx               # Индикаторы свайпа (затемнение, лайк)
│   ├── EmptyState.tsx                    # Пустые состояния
│   ├── LimitReachedOverlay.tsx           # Оверлей лимита
│   └── ... (существующие компоненты)
├── hooks/
│   ├── useTelegramInit.ts                # Инициализация Telegram
│   ├── useSwipeLimits.ts                 # Управление лимитами
│   └── useSwipeGestures.ts               # Жесты свайпа
├── utils/
│   └── telegram.ts                       # Утилиты Telegram (getUserId)
└── types/
    └── networking.ts                     # Типы (NetworkingProfile)
```

## Компоненты

### Карточка профиля (ProfileCard)

Разбита на 8 подкомпонентов:

1. **ProfileCard** - главный компонент
2. **ProfileCardContainer** - контейнер с анимациями
3. **ProfileCardPhoto** - фотография с градиентом
4. **ProfileCardAura** - аура (большая и верхняя)
5. **ProfileCardCases** - летающие кейсы
6. **ProfileCardButtons** - кнопки управления
7. **ProfileCardInfo** - имя и описание
8. **ProfileCardTags** - теги под карточкой

### Вспомогательные компоненты

#### AdCardWrapper

Обертка для рекламной карточки с эффектом тряски при попытке свайпа.

**Особенности:**

- Ограничение движения до 50px
- Вибрация при попытке свайпа
- Анимация тряски 500ms
- Поддержка touch и mouse событий

#### CardHeader

Заголовок над карточкой с городом и плашками "Что ищет".

**Компоненты:**

- Иконка и название города (обрезка до 15 символов)
- LookingForBadges (существующий компонент)

#### SwipeIndicators

Визуальные индикаторы при свайпе.

**Индикаторы:**

- Затемнение при свайпе влево (пропуск)
- Изображение лайка при свайпе вправо
- Плавное появление/исчезновение

#### EmptyState

Пустые состояния приложения.

**Типы:**

- `no-user-id` - нет userId от Telegram
- `no-profiles` - нет профилей для показа
- `loading` - загрузка (использует MatchLoader)

#### LimitReachedOverlay

Оверлей при достижении лимита свайпов.

**Особенности:**

- Затемненный фон
- Таймер до сброса лимита
- Кнопка открытия подписки
- Блокировка взаимодействия с карточками

## Хуки

### useTelegramInit

Инициализация Telegram WebApp.

**Возвращает:**

- `isPlatformDesktop` - флаг десктопной платформы

**Действия:**

- Настройка стилей body
- Инициализация Telegram WebApp
- Определение платформы
- Настройка BackButton

### useSwipeLimits

Управление лимитами свайпов и лайков.

**Возвращает:**

- `swipesCount` - количество свайпов
- `likesCount` - количество лайков
- `limitReached` - достигнут ли лимит
- `limitMessage` - сообщение о лимите
- `timeUntilReset` - время до сброса
- `loadCounts` - загрузка счетчиков
- `incrementSwipes` - увеличить свайпы
- `incrementLikes` - увеличить лайки
- `SWIPES_LIMIT` - лимит свайпов (50)
- `LIKES_LIMIT` - лимит лайков (20)

**Особенности:**

- Хранение в Telegram Cloud Storage
- Автоматический сброс в полночь
- Таймер обратного отсчета
- Проверка лимитов при загрузке

### useSwipeGestures

Обработка жестов свайпа.

**Параметры:**

- `isSwipeDisabled` - заблокирован ли свайп
- `limitReached` - достигнут ли лимит
- `hasActiveSubscription` - есть ли подписка
- `onSwipeLeft` - колбэк свайпа влево
- `onSwipeRight` - колбэк свайпа вправо

**Возвращает:**

- `dragOffset` - смещение при свайпе
- `isDragging` - идет ли перетаскивание
- `setDragOffset` - установить смещение
- `handleTouchStart` - обработчик touch start
- `handleTouchMove` - обработчик touch move
- `handleTouchEnd` - обработчик touch end
- `handleMouseDown` - обработчик mouse down

**Особенности:**

- Поддержка touch и mouse событий
- Сопротивление 0.8 для плавности
- Порог свайпа 70px
- Haptic feedback
- Глобальные обработчики мыши

## Утилиты

### getUserId

Получение userId из Telegram WebApp.

**Особенности:**

- Несколько способов получения ID
- Парсинг initData если нужно
- Логирование для отладки
- Возврат null если ID не найден

## Типы

### NetworkingProfile

Интерфейс профиля пользователя.

**Поля:**

- `id` - ID профиля
- `networkingName` - имя в нетворкинге
- `firstName` - имя из Telegram
- `username` - username из Telegram
- `networkingPhoto` - фото профиля
- `networkingLocation` - город
- `networkingAbout` - о себе
- `networkingSkills` - навыки
- `networkingValues` - ценности
- `networkingAura` - аура (NONE | TURQUOISE | ORANGE | RED)
- `networkingLookingFor` - что ищет
- `networkingGender` - гендер
- `networkingCases` - кейсы
- `hasWorkProfile` - есть ли work профиль
- `primarySkill` - основной навык

## Главная страница (page.tsx)

### Структура

Страница теперь значительно короче и читабельнее:

- ~1000 строк → ~700 строк
- Вся логика разбита на хуки и компоненты
- Четкое разделение ответственности

### Основные секции

1. **Импорты** - все компоненты и хуки
2. **Константы** - изображения для предзагрузки, частота рекламы
3. **Состояние** - useState для всех данных
4. **Хуки** - useTelegramInit, useSwipeLimits, useSwipeGestures
5. **Эффекты** - инициализация, загрузка профилей
6. **Обработчики** - handleLike, handlePass, handleExpressLove
7. **Рендер** - условный рендер состояний и карточек

### Логика работы

#### Инициализация

1. Инициализация Telegram WebApp
2. Проверка заполненности профиля
3. Загрузка своего профиля
4. Загрузка счетчиков лимитов
5. Загрузка профилей для свайпа

#### Свайп

1. Проверка лимитов (если нет подписки)
2. Блокировка свайпов на время анимации
3. Установка минимального offset для видимости
4. Запуск анимации улета
5. Haptic feedback
6. Увеличение счетчиков
7. Отправка запроса на бэк
8. Переключение на следующую карточку
9. Проверка мэтча (для лайка)

#### Реклама

- Показывается каждую 20-ю карточку
- Нельзя свайпнуть (тряска при попытке)
- Можно закрыть или открыть подписку

#### Лимиты

- 50 свайпов в день
- 20 лайков в день
- Хранение в Telegram Cloud Storage
- Сброс в полночь
- Оверлей при достижении лимита
- Таймер обратного отсчета

## Преимущества рефакторинга

### Читаемость

- Код разбит на логические блоки
- Каждый компонент отвечает за одну задачу
- Легко найти нужный код

### Поддержка

- Изменения в одном компоненте не влияют на другие
- Легко добавлять новые фичи
- Легко тестировать отдельные части

### Переиспользование

- Компоненты можно использовать в других местах
- Хуки можно использовать на других страницах
- Утилиты доступны везде

### Производительность

- Меньше ре-рендеров
- Оптимизированные анимации
- Ленивая загрузка профилей

## Миграция

Старый файл сохранен как `page_old.tsx` для справки.

### Что изменилось

1. Карточка разбита на 8 компонентов
2. Логика свайпа вынесена в хук
3. Лимиты вынесены в хук
4. Telegram инициализация вынесена в хук
5. Пустые состояния вынесены в компонент
6. Индикаторы свайпа вынесены в компонент
7. Оверлей лимита вынесен в компонент
8. Реклама обернута в компонент с тряской

### Что осталось

- Вся функциональность работает как раньше
- Все анимации сохранены
- Все стили сохранены
- Все API запросы сохранены
